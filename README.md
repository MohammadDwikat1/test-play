# Pong Game

## About the Game

This is a two-player Pong game made using Lua and LÖVE2D. Both players control a paddle and try to hit the ball to keep it inside the game area. Each player gets a point when the ball passes the opponent's side. The first goal is to hit the ball and score as many points as possible.

## How to Run

To play the game, make sure LÖVE is installed on your computer. Open the project folder in the terminal and run:

```bash
love .
```

## Controls

- **Player 1:** Use W to move up and S to move down.
- **Player 2:** Use the Up Arrow to move up and the Down Arrow to move down.

## Extra Feature

I added different colors to the two paddles to make it easier to tell the players apart. The left paddle is blue, and the right paddle is red. I also added a small speed increase whenever the ball hits a paddle, making the game a little more challenging as it continues.
